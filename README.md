# mapper-3d

PL/EL 이미징 + LBIC 통합 지도 장치 개념 3D (2026-11-19). 제작 도면이 아닌 개념 조립 모델입니다.

- 지지 구조: 미스미 알루미늄 프로파일(HFSB6-3060 기둥 2, HFSB6-3030 가로대·보강·머리 레일·팔 레일)과 브래킷·후입 너트·끝 마개는 미스미 STEP 파일 그대로, 광학 부품(Thorlabs)은 제조사 STEP 파일 그대로 썼습니다. STEP이 없는 부품(C4W 큐브, 볼트, 광섬유 등)만 직접 그렸습니다.
- 장면: 탠덤 지그, 빔라인 셀, 메모리 지그, SM 지그 (10× 대물), 그리고 1× 렌즈 위치(머리 레일을 올린 상태).
- "조립 단계" 선택(1–8단계): 밑에서부터 그 단계까지의 부품만 보입니다. 부품을 누르면(탭) 위쪽 띠에 이름과 품번이 나옵니다.
- 간섭 검사는 모든 부품 쌍에 대해 했고, 결과는 설계 문서(통합 지도 장치 설계, 10절)에 있습니다.
- 2026-11-19 수정: 케이지 막대를 실제 파는 길이로 다시 했습니다(큐브 A–B, C4W–합치기 큐브: ER05 + ERSCB05, 레이저 팔: ER4 + ERSCB1). ELL9K의 제어 기판(ELLC 인터페이스 보드)과 리본 케이블은 제조사 구성품이지만 따로 두기로 해서 모델에서 뺐습니다. 떠 있는 부품이 없는지 지지 연결을 전부 확인했습니다(0건).
